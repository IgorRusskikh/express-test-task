# Express-Gen-TS

Современный шаблон сервера на базе Express.js с использованием TypeScript и Prisma ORM для быстрого старта разработки RESTful API.

## Особенности

- **TypeScript** - строгая типизация для более надежного кода
- **Express.js 5** - быстрый и минималистичный веб-фреймворк
- **Prisma ORM** - современный ORM для работы с базой данных
- **Аутентификация** - готовая система с JWT и Passport.js
- **Валидация** - проверка входных данных
- **Логирование** - настроенное логирование с jet-logger
- **Docker** - поддержка контейнеризации для легкого развертывания

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
# Клонирование репозитория
git clone [репозиторий-проекта]
cd express-gen-ts

# Установка зависимостей
npm install

# При проблемах с зависимостями можно выполнить чистую установку
npm run clean-install
```

## Настройка

### Основная настройка

1. Создайте файл `.env` из примера `.example.env`:

```bash
cp .example.env .env
```

2. Отредактируйте `.env` файл, настроив следующие параметры:
   - `PORT` - порт для запуска сервера (по умолчанию 3000)
   - `NODE_ENV` - окружение (development, production, test)
   - `JWT_SECRET` - секретный ключ для JWT токенов
   - `COOKIE_SECRET` - секретный ключ для cookie
   - Настройки подключения к базе данных

### Настройка базы данных

1. Укажите строку подключения к базе данных в `.env` файле:

```
DATABASE_URL="postgresql://username:password@localhost:5432/database_name"
```

2. Запустите миграции Prisma для создания схемы базы данных:

```bash
npx prisma migrate dev
```

3. При необходимости сгенерируйте Prisma клиент:

```bash
npx prisma generate
```

## Запуск приложения

### Разработка

```bash
# Стандартный запуск в режиме разработки
npm run dev

# Запуск с горячей перезагрузкой (отслеживание изменений)
npm run dev:hot
```

Сервер по умолчанию запустится на порту 3000 (или на порту, указанном в `.env`).
Доступ к API: `http://localhost:3000`

## Docker

Проект включает настроенный Docker Compose для легкого запуска в контейнере:

```bash
# Запуск приложения и базы данных через Docker Compose
docker-compose up

# Запуск в фоновом режиме
docker-compose up -d

# Остановка контейнеров
docker-compose down
```

Docker Compose запустит:

- Сервер приложения
- PostgreSQL базу данных (если настроено в docker-compose.yml)

```
│   ├── middleware/         # Промежуточные обработчики

│   ├── common/             # Общие утилиты и функции
│   ├── use-cases/          # Бизнес-процессы
│   ├── server.ts           # Настройка Express сервера
│   └── index.ts            # Точка входа приложения
├── prisma/                 # Схема и миграции Prisma
├── config/                 # Конфигурационные файлы
├── scripts/                # Скрипты для автоматизации
└── uploads/                # Директория для загруженных файлов
```
